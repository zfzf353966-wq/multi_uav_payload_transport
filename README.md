#无人机协同吊运项目
# Multi UAV Payload Transport

## Overview

Cooperative transportation of cable-suspended payload by multiple UAVs.

## Environment

- Ubuntu 22.04
- ROS2 Humble
- Gazebo Harmonic
- PX4 SITL

## Goal

Develop a multi-UAV cooperative transportation simulation system.

## Planned Features

- Multi UAV formation control
- Cable-suspended payload modeling
- Payload dynamics
- Anti-swing control
- Cooperative trajectory tracking
