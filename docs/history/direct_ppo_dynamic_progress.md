# 三维纯 PPO 动态避障推进记录

## 已确认的失败模式

使用 `dynamic_bounded_guarded_v1/best_model.zip`，在原测试种子 1100000 起复现 1000 回合，得到 978 成功、22 碰撞，与原指标一致。

- 22 次碰撞全部发生在避让阶段，没有提前进入 recovery，也没有标记已通过。
- 20 次碰撞接近期间仍能看到障碍；2 次出现短时竖直观测盲区。
- 若将实时方向制动判定离线应用于碰撞轨迹，平均约 70.6% 的步会触发制动；这是离线判定，不是加制动后的闭环成功率。
- 多个失败样本开局机体净距仅为 0.6–3 m，需要更早决定侧移、上下避让、减速或后退。

诊断命令：

```bash
source scripts/setup_env.bash
PYTHONPATH="$PWD/src/logistics_planner${PYTHONPATH:+:$PYTHONPATH}" \
python -m logistics_planner.analyze_direct_ppo \
  --model runs/direct_ppo_3d/dynamic_bounded_guarded_v1/best_model.zip \
  --stage dynamic --seed 1100000 --episodes 1000 \
  --reward-version 3 --safety-guards \
  --output-dir runs/direct_ppo_3d/analysis_dynamic_v1
```

## 已完成的对照

### 显式运动特征与任务前历史

`TemporalDirectPPOFeatures` 从已有四帧提取 108 个扇区距离变化率，拼接到原 153 个特征之后。策略外部观测仍为 153 维。新输入权重初始化为零，保持初始动作和价值估计一致；两组均重启优化器。

`--history-warmup` 进一步模拟任务前已经运行的激光，在无人机初始位置采样障碍过去 0.3 秒的轨道位置。当前障碍位置、速度、目标、场景参数保持一致，避免用同一瞬间的扫描重复填充历史。此项改变了开局可用历史，不能与无历史的结果混为同一种评估条件。

训练均追加 200000 步，种子 62，学习率 5e-5；验证 64000 起 200 回合，最终测试 1300000 起 1000 回合。

| 方案 | 成功率 | 碰撞率 | 越界/超时 |
|---|---:|---:|---:|
| 普通续训对照 | 97.4% | 2.6% | 0 |
| 距离变化率特征 | 97.1% | 2.9% | 0 |
| 距离变化率 + 任务前历史 | 97.4% | 2.6% | 0 |

未显示出改善，暂不作为默认配置。可选功能和检查保留，供后续多场景实验使用。

### 竖直优先速度预算

原径向限幅会同时缩小三个速度分量。例如 `[1,1,1]` 动作先映射到 `[2,2,1] m/s`，总速度限幅后竖直分量降为约 0.67 m/s。

可选 `vertical_priority` 映射保留上/下速度，在总速度不超过 2 m/s 的条件下分配剩余水平预算。映射保存在 PPO 模型中，推理自动读取；旧模型默认 `radial`，不会静默改变解释方式。

未重训诊断中，同一模型、原 1100000 起测试集的碰撞率由 2.2% 变为 1.2%。随后追加 200000 步，并在新的 1500000 起 1000 回合测试：成功率 98.1%、碰撞率 1.9%，仍未过门槛。最佳检查点为 0 步，说明该轮续训未优于映射切换后的初始候选；不把此结果表述为训练获得的提升。

### 近距离相遇样本重采样

新增训练参数 `--hard-case-probability 0.5`：约一半回合专门从合法原始场景分布中拒绝采样初始机体净距 0.5–3.5 m 的场景，其余回合保持原分布。不改变障碍半径、轨道参数、动作上限或评估难度。

验证和最终测试始终使用 `hard_case_probability=0`。两组共同使用原动态模型，重启优化器，训练种子 72、学习率 1e-4、200000 步，验证 66000 起 200 回合，测试 1600000 起 1000 回合。

| 方案 | 成功率 | 碰撞率 | 最小机体净距均值 |
|---|---:|---:|---:|
| 原分布续训对照 | 96.9% | 3.1% | 1.65 m |
| 近距离样本重采样 | 98.3% | 1.7% | 1.80 m |

重采样组训练中验证集一度达到 100%，最终独立测试仍有 17 次碰撞，故不能宣称已通过 ≤1% 门槛。后续从该模型继续，保留普通分布测试。

## 相关探索对照（已完成）

普通逐帧独立随机探索与状态相关探索分别追加 200000 步。后者每 8 个控制步重新采样探索偏移（名义约 0.8 秒），鼓励尝试持续的避让动作。确定性推理接口仍是 PPO 三维速度，没有势场输出。

两组从 `dynamic_hard_cases_v1/best_model.zip` 出发，复制相同确定性策略与价值参数，均重启优化器，使用 50% 近距离场景训练、种子 82、学习率 1e-4。验证集为 67000 起 200 回合，最终测试为 1800000 起 1000 回合；短训练检查使用另一个测试集，不与最终测试混用。

输出：

- `runs/direct_ppo_3d/dynamic_sde_ablation/control/`
- `runs/direct_ppo_3d/dynamic_sde_ablation/correlated/`

相关探索只改变训练采样方式。保存模型包含该策略配置，加载后确定性输出一致；已有单元测试覆盖训练与序列化。当前训练状态和结果以实际进程、`validation.json`、`metrics.json` 为准。

最终 1000 回合：普通探索成功率 98.6%、碰撞率 1.4%；相关探索成功率 98.5%、碰撞率 1.5%。未显示改善，保留普通探索模型。

上述结果均为轻量环境，不能等同于 Gazebo/PX4 飞行成功率。后续已完成传感器校准、修复障碍生成路径，并跑通两个单障碍原型场景，完整结果与限制见 [原型演示说明](ppo_demo.md)。其中修复路径前的试飞没有实际生成目标球，不作为动态避障能力证据。多动态障碍验证尚未完成。
